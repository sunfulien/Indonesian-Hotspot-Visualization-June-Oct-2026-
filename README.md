How to replicate the project:  
1. install all requirements from requirements.txt
2. Open and run in folder code: dataset_cleaner.ipynb
3. Open and run visualization_highres_final.ipynb
4. Final mp4 will be returned in folder output/video_output

Dataset:
1. You can grab dataset from https://firms.modaps.eosdis.nasa.gov/download/
2. Remove the readme in each dataset folder before running dataset_cleaner.ipynb

Note: 
the folder legacy entails the trial version of this project using data from January to October (before 31st) 2026 with only Indonesian dataset.
